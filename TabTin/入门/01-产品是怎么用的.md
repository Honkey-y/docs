# 产品是怎么用的

> 状态：草稿
> 最后更新：2026-09-08
> 适用范围：TabTin 新人产品入门
> 关联文档：[入门目录](说明.md) · [下一篇：核心概念](02-核心概念.md)

**TabTin 把 AI 助手和工作工具放在一起，让一件事从“提出目标”一直做到“留下结果”。**

这里的 AI 助手叫智能体（Agent）。它可以理解要求，并在获得相应权限后，使用文档、表格、浏览器、文件和终端等工具完成工作。人可以查看过程、补充要求、修改结果。

## 用户从哪里开始

| 入口 | 用户此时的想法 | 例子 |
| --- | --- | --- |
| 任务 | 我知道想要的结果，交给 Agent 做 | “把这些入职资料整理成学习清单。” |
| 应用 | 我要直接处理一个东西，需要时再叫 AI | 打开学习清单，自己编辑，再请 AI 补充说明 |

两种方式围绕同一份工作成果展开。例如 Agent 做好一篇文档后，你可以直接打开继续改；自己编辑时，也可以让 AI 帮忙处理当前内容。

## 用一个小例子理解完整体验

假设你想整理一份“入职学习清单”。

1. **交代目标和材料。** 告诉 Agent：“根据我提供的入职资料，整理今天、本周、以后要学的内容。”
2. **看它怎样处理。** Agent 阅读材料、整理内容，必要时请求补充信息或操作授权。
3. **检查实际成果。** 如果你要求生成 TabDoc，就打开那篇文档，确认它存在、内容正确、可以编辑。
4. **继续一起修改。** 你可以手改，也可以说：“把今天的内容缩成三项，每项加一个完成标准。”

这个例子的价值在于：要求、处理过程和成果能连起来，后续还可以继续做。

## 常见应用先认这些

应用（App）是平台里做具体工作的入口。一份“学习清单”是文档资源，TabDoc 是打开和编辑它的应用。

| 你要做的事 | 常见入口 |
| --- | --- |
| 写说明、整理资料 | TabDoc：文档 |
| 整理记录、筛选和统计 | TabData：数据表 |
| 浏览网页、查找资料 | Browser：浏览器 |
| 处理本地文件、运行命令 | TabFolder：文件；Terminal：终端 |
| 和同事交流 | TabChat：聊天 |

开发、调研、运营和内容制作都能使用这些能力。业务目标可以变化，产品提供通用的工作工具。

## 你入职后首先关注什么

体验一个功能时，问三个问题：**人在哪里操作？Agent 能怎样参与？结果到哪里找？**

例如“生成学习清单”，完成标准是能找到并继续编辑清单。对话里出现“已经做好了”，还需要用实际成果验证。
