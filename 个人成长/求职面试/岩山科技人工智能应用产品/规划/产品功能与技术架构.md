## 一、产品功能架构

### 1.1 功能模块

| 功能模块 | 子功能 |
|---|---|
| 社区内容 | 发布穿搭求助、内容推荐、最新内容、话题内容、搭配结果展示 |
| 社区互动 | 点赞、评论、收藏、分享、关注、帮她搭配、举报 |
| 搭配共创 | 设置场景与要求、选择开放衣物、拖拽搭配、AI效果生成、方案提交、方案采纳 |
| 穿着反馈 | 是否实际穿着、效果评价、未采用原因、搭配复用 |
| 衣橱管理 | 衣物上传、AI抠图、自动分类、属性编辑、公开范围、搭配记录 |
| 数字形象 | 数字形象创建、形象更新、3D展示、服装试穿、隐私授权、形象删除 |
| 用户资产 | 个人资料、我的求搭、我的搭配、被采纳记录、收藏记录 |
| 智能推荐 | 求搭内容推荐、搭配参与者匹配、衣物组合建议、相似搭配推荐 |
| 内容安全 | 图片审核、评论审核、恶意搭配识别、身体羞辱识别、举报处理 |
| 运营管理 | 用户管理、内容管理、话题运营、推荐配置、AI任务管理、数据分析 |
| 电商扩展 | 候选商品导入、与已有衣橱试搭、购买跳转、佣金归因、商品质量反馈 |
| 二手扩展 | 闲置衣物识别、二手资料生成、第三方平台跳转 |

## 二、核心业务流程

~~~

### 3.2 各层职责

| 架构层 | 职责 |
|---|---|
| 产品应用层 | 承载穿搭社区、衣橱、数字形象、搭配共创及运营后台 |
| 业务能力平台 | 提供社区、互动、求搭、衣橱、方案、用户和反馈能力 |
| AI能力平台 | 提供衣物处理、数字形象、3D试穿、推荐、质量评测和内容安全 |
| 基础平台 | 提供账号、权限、媒体资产、任务、消息、数据和配置能力 |
| 外部能力 | 对接公司多媒体底座、第三方模型、电商平台和云资源 |
| 管理与治理 | 统一负责社区运营、风控、AI质量、成本、数据和安全 |

## 四、架构边界

- “帮她搭配”属于社区互动和搭配共创能力，不建设独立游戏产品。
- 不建设搭配师后台、创作者后台、商家后台和微信公众号。
- AI能力嵌入穿搭流程，不单独面向用户提供通用Agent入口。
- MVP不建设完整电商交易，只保留后续商品接入能力。
- 3D试穿用于搭配示意，不承诺真实尺码、面料和到手效果。
