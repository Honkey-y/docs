> 关联文档：[专题说明](../说明.md)、[项目机会池](项目机会池.md)、[项目选题不以现有 Agent 为硬约束](../决策记录/2026-09-06-项目选题不以现有智能体为硬约束.md)

## 一、核心结论

长期愿景可以定义为：

> 帮助女性以更低的试错成本完成从风格灵感、虚拟体验、学习实践、购买决策、衣橱管理到闲置流转的个人形象决策。

它不是简单叠加试妆、试衣、试发型、衣橱、二手和护肤功能，而是围绕同一份个人审美档案持续回答四个问题：

1. 这个风格在我身上会是什么效果？
2. 我应该怎样实现这个效果？
3. 我已有的东西能否满足，还需要购买什么？
4. 买入以后怎样使用，不再需要时怎样处置？

长期平台愿景有吸引力，但不适合作为首版范围。建议采用“一个愿景、一个切口、多阶段扩张”：

- **长期愿景**：个人风格与变美决策平台。
- **首发产品**：妆容灵感试用与学习。
- **首发承诺**：给我一张自拍和一个妆容灵感，返回保留身份的试妆效果、适配说明和可执行化妆步骤。
- **暂不进入首版**：试衣、完整衣橱、二手交易、肤质诊断、自动抓取外部内容和自动购买。

## 二、目标用户与首发场景

### 2.1 首发目标用户

优先服务 18–35 岁、已经通过内容平台获取妆容灵感，但缺少试错信心或化妆经验的女性用户。

首发进一步聚焦以下人群：

- 化妆初学者：看得懂效果，但不知道如何复现。
- 有明确场合需求的用户：约会、通勤、面试、婚礼或旅行前，需要快速判断妆容是否适合。
- 容易冲动购买的用户：希望在购买彩妆前先看到近似效果和使用价值。
- 经常收藏教程但很少行动的用户：收藏内容与个人执行之间存在断层。

### 2.2 首发用户任务

> 当我看到一个喜欢的妆容时，我希望先看到它在自己脸上的可信效果，并获得适合我的操作步骤，以便决定是否学习、购买或放弃。

### 2.3 非目标

首版不承诺：

- 判断用户是否“漂亮”或给出外貌等级。
- 精确还原实体商品的最终色差、质感和持妆效果。
- 诊断皮肤疾病或替代皮肤科医生。
- 未经授权抓取、复制或重新分发内容平台的图文与视频。
- 代替用户完成外部平台购买、发布或二手交易。

## 四、首发产品：妆容灵感试用与学习

### 4.1 产品形态

首发版本包含五个稳定的产品对象：

| 产品对象 | 作用 | 首版内容 |
|---|---|---|
| 个人档案 | 保存用户主动提供的妆容偏好和基础约束 | 偏好风格、常见场合、可选肤色描述；不保存外貌评分 |
| 灵感妆容 | 表达用户想尝试的效果 | 平台授权模板或用户有权使用的参考图片 |
| 试妆任务 | 管理一次生成与质量状态 | 原始自拍、参考妆容、生成策略、质量评分、失败原因 |
| 妆容方案 | 承载用户可比较和保存的结果 | 试妆图、适配说明、需调整部位、风险提示 |
| 学习卡 | 把效果转成可执行步骤 | 分区步骤、手法、工具、替代色系与预计时间 |

首版不要求用户理解底层 Agent。用户看到的是明确的试妆任务、候选对比、学习步骤和失败处理；底层能力只负责解析、路由、生成、评测和回退。

### 4.3 首次价值时刻

用户完成以下行为时，视为达到首次价值：

> 在一次会话中生成至少一个通过质量门控的结果，并保存试妆方案、打开学习卡或明确标记“不适合我”。

“不适合”同样是有效结果，因为产品的价值是降低错误尝试和错误购买，而不是迫使用户接受生成内容。

### 4.4 北极星指标

建议使用“每周完成的有效风格决策数”，而非生成图片数。

一次有效决策至少满足以下一项：

- 用户保存方案并在 7 天内再次查看。
- 用户完成学习卡中的练习并反馈结果。
- 用户因试用结果明确放弃不合适的妆容或商品。
- 用户进入经清晰标注的购买、预约或授权教程页面。
- 用户将方案加入后续场景或衣橱搭配。

## 六、阶段路线图

### 6.1 阶段一：妆容试用与学习

- 复用已有虚拟试妆 Workflow。
- 建立授权妆容模板库、候选对比和个性化学习卡。
- 验证身份保持、迁移效果、首次价值、分享和付费。

### 6.2 阶段二：发型与场合造型

- 扩展发型长度、颜色和轮廓试用。
- 将妆容与发型组合为通勤、约会、面试等完整场景方案。
- 验证用户是否需要跨品类建议，而非只使用单次试妆。

### 6.3 阶段三：衣橱与日常搭配

- 用户拍摄或导入真实衣物，平台完成分类、去重和可编辑属性识别。
- 优先推荐已有衣物组合，再考虑新增购买，建立“少买但更合适”的信任。
- 以每周搭配使用率和衣橱维护率判断是否形成高频价值。

### 6.4 阶段四：商品与服务合作

- 接入有授权的品牌商品、本地门店服务和内容创作者。
- 所有付费排序、佣金链接和商业合作明确标识。
- 推荐原因同时包含“为什么适合”和“不确定性”，不以佣金高低替代适配度。

### 6.5 阶段五：闲置发布助手

- 首先输出真实商品图片、瑕疵说明、规格和可复制发布资料包。
- 不在首版代用户登录、自动发布、议价、收款或承担交易平台职责。
- 与二手平台建立正式合作后再评估深度集成。

### 6.6 阶段六：非医疗护肤建议

该方向风险最高，建议最后进入。首版只能描述可观察的肤表特征和一般性护理建议，不诊断痤疮、皮炎、色素疾病等医学问题，不承诺治疗效果；出现高风险症状时，引导用户咨询专业医生。

## 七、小红书内容链接方案

### 7.1 主要风险

“找到小红书上这个妆容的链接”本身不必然违规，具体风险取决于实现方式。需要分别评估：

- **平台规则风险**：批量抓取、绕过登录或反爬机制、模拟用户操作、深度链接是否违反当时有效的平台服务条款和开放平台规则。
- **著作权风险**：复制标题、图片、视频、教程步骤或在本产品内重新展示，可能涉及复制、信息网络传播和改编。
- **不正当竞争风险**：大规模聚合并替代原平台浏览、截取商业流量或去除作者与来源，可能产生争议。
- **个人信息风险**：抓取作者账号、头像、互动数据和用户评论会扩大个人信息处理范围。
- **商业推荐风险**：如果链接带佣金、付费排序或品牌合作，需要清晰标识商业关系。

以上为产品风险识别，不构成法律意见；正式上线前需由法务结合具体实现和届时平台规则审核。

### 7.2 建议的分阶段方案

首版采用低风险方案：

1. 建立平台自有的授权妆容模板库，与化妆师或内容创作者签署使用与衍生生成授权。
2. 允许用户保存原始外部链接并跳回原平台浏览，但不自动抓取、缓存或重新展示原内容。
3. 用户上传参考图时要求确认其有权使用，同时设置投诉、删除和重复侵权处理机制。
4. 对生成的学习卡只输出基于用户面部和授权妆容模板形成的新步骤，不复制外部教程原文。
5. 如需搜索或展示小红书内容，优先通过官方开放接口、正式商务合作或创作者主动入驻实现。

不建议首版采用：

- 后台批量抓取小红书内容并建立镜像妆容库。
- 下载视频、去水印或在本产品内直接播放未授权内容。
- 未经作者同意使用其脸部、声音或教程训练商业模型。
- 伪装普通用户自动关注、收藏、评论或私信。

## 八、安全、隐私与合规边界

| 风险领域 | 产品风险 | 首版控制 |
|---|---|---|
| 自拍与人脸 | 人脸图像可能构成敏感个人信息；泄露或滥用后果严重 | 单独同意、目的限定、最少保存、可随时删除、传输与存储加密、默认不用于模型训练 |
| AI 生成内容 | 用户或第三方可能把试妆图误认为真实照片 | 按适用规定添加显式与文件元数据标识，分享时保留标识 |
| 未成年人 | 审美压力、个人信息和消费诱导风险更高 | 首发限定成年人；未来进入未成年人场景需单独评估监护人同意与产品设计 |
| 外貌评价 | 强化单一审美、制造焦虑或歧视 | 不做颜值评分；用“偏好、场合、可操作性和用户反馈”表达适配 |
| 虚拟试衣 | 生成效果无法准确代表尺码、面料和实物色差 | 明示为视觉模拟，不提供合身保证；商品图片和品牌元素必须获得授权 |
| 护肤建议 | 可能跨入疾病诊断、治疗建议或夸大功效 | 仅限非医疗信息；高风险症状转介医生；商品功效必须有可核验依据 |
| 商业推荐 | 佣金可能扭曲排序并损害用户信任 | 标记广告、赞助和佣金；提供非商业结果和关闭个性化推荐的入口 |
| 二手服务 | 深度介入交易会产生平台治理、争议处理和商品真实性责任 | 首期只做发布资料助手，交易留在正式合作平台完成 |

需由法务重点核验的中国法规包括《中华人民共和国个人信息保护法》《中华人民共和国广告法》《中华人民共和国电子商务法》《互联网信息服务算法推荐管理规定》《互联网信息服务深度合成管理规定》《人工智能生成合成内容标识办法》和《化妆品功效宣称评价规范》，以及届时有效的小红书平台规则与开放平台协议。

## 九、商业模式

### 9.1 首发收入

- 免费用户获得有限次数和标准清晰度试妆。
- 个人会员按月或按年付费，获得高清结果、更多候选、历史方案、学习卡和场景收藏。
- 单次点数包服务低频用户，但必须设置清晰的生成失败退款或点数返还规则。

### 9.2 平台扩展收入

- 经明确标识的商品或服务佣金。
- 美妆品牌和美业门店的授权模板、活动工作台与效果分析。
- 内容创作者模板分成。
- 衣橱高级管理、多人家庭或专业造型师协作订阅。
- 二手平台正式合作后的线索或服务收入。

商业化必须晚于用户信任：首发首先证明用户愿意反复用它做决策，再接入商品推荐。过早佣金化会使用户怀疑推荐结果服务于商家而非自己。

## 十、增长机制

- **可分享结果**：生成包含原妆灵感来源、AI 标识和个人调整说明的对比卡；分享不暴露原始自拍。
- **授权创作者模板**：创作者发布可试用妆容，用户体验后返回其原始教程或购买其课程，形成分成。
- **场景挑战**：围绕通勤、面试、旅行等任务组织低门槛挑战，而非围绕颜值排名。
- **练习反馈**：用户上传实际完成效果，获得步骤调整；分享学习进步比分享单张生成图更有留存价值。
- **衣橱邀请**：进入衣橱阶段后，允许用户邀请朋友或造型师协助搭配，但默认不公开个人衣物与身体信息。

## 十一、MVP 建议

### 11.1 六周范围

- 30 个获得使用授权的妆容模板。
- 自拍质量检测和单独同意流程。
- 身份保持与妆容迁移生成。
- Identity Score、Transfer Score、Artifact Penalty 质量门控与 Fallback。
- 三个候选结果对比。
- 一份基于面部区域的个性化学习卡。
- 保存、删除、反馈和带 AI 标识的分享。
- 生成成本、失败原因和用户行为漏斗看板。

### 11.2 MVP 验证问题

1. 用户是否认为生成结果“仍然是自己”？
2. 用户是否能看懂妆容迁移了什么，而不是只觉得滤镜好看？
3. 用户是否会保存方案、打开学习卡或再次试用？
4. 用户是否愿意为更高质量、更多方案或持续档案付费？
5. 单次合格结果的生成成本和等待时间能否支持目标价格？
6. 哪一类妆容、人脸角度或肤色最容易失败，是否可以通过收窄首发范围控制？

### 11.3 建议的阶段门槛

具体数值需要通过种子用户基线校准。面试稿可先提出以下验证口径，不宜在没有测试数据时承诺固定百分比：

- 质量门槛：身份保持、妆容迁移和瑕疵三项均达到人工评审的可接受标准。
- 首次价值门槛：合格生成用户中有明确比例完成保存、学习或“不适合”反馈。
- 留存门槛：首周用户在新妆容或新场景下主动再次使用。
- 商业门槛：目标用户愿意支付的价格能够覆盖生成、审核、存储和获客成本。
- 风险门槛：重大人脸泄露、未授权内容使用和误导性健康建议为零容忍事件。

## 十二、面试表达建议

不要以“女生想到变美就想到我们”开场，因为它会先暴露范围过大。建议使用以下层次：

1. **愿景**：成为女性的个人风格决策平台。
2. **问题**：内容平台解决了“看到喜欢的”，但没有解决“是否适合我、如何做到、是否值得买”。
3. **切口**：从你已经完成技术验证的妆容迁移进入。
4. **产品**：试妆结果不是终点，后面连接个性化学习和真实决策。
5. **扩张**：当个人审美反馈成立后，再依次进入发型、衣橱、购买和闲置。
6. **优势**：你既做过虚拟试妆工作流，也做过生活服务商家的 AI 咨询与转化产品，能够覆盖体验与商业闭环。
7. **公司协同**：项目可用现有方案独立验证；若公司 Agent 和多媒体底座适配，可显著加快多品类扩展和规模化生产。

## 十三、待确认事项

1. 已有虚拟试妆原型的实际生成耗时、成功率、单次成本和可展示素材。
2. 是否拥有可邀请进行首轮测试的女性用户、化妆师、美妆门店或内容创作者。
3. 首发更适合化妆初学者，还是婚礼、面试等强场景用户。
4. 用户更愿意为生成质量、学习指导、长期个人档案还是购买优惠付费。
5. 公司现有 Agent 与多媒体底座能否直接支持身份保持、局部迁移、角色一致性、质量评测和生成日志。
6. 面试材料是否需要可交互原型、录屏演示或真实试用数据。
7. 小红书届时有效的平台规则、开放能力和商务合作可能性。
8. 肤质相关功能的医学、化妆品、广告和算法合规评审责任人。
