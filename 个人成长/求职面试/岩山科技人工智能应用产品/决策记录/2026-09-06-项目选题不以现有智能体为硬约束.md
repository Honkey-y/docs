# 项目选题不以现有 Agent 为硬约束

> 状态：已确认
> 最后更新：2026-09-06
> 适用范围：岩山科技 AI Agent 项目负责人面试自带项目的选题边界
> 关联文档：[项目机会池](../规划/项目机会池.md)

## 背景

岗位信息重点介绍公司现有 Agent 和多媒体生产底座，容易将选题范围理解为“必须基于公司现有 Agent 孵化产品”。

## 新增事实

2026-09-06，申请人补充了 HR 电话沟通信息：

> 不基于公司现有 Agent 的项目也可以提交，公司会一并评审。

该信息为申请人转述。后续如获得书面评审标准，以书面版本为准。

## 决策

1. 候选项目首先按用户价值、商业可行性、申请人优势和 MVP 可验证性排序。
2. 现有 Agent、多媒体底座和存量渠道作为“可复用优势”评估，不作为入围前提。
3. 每个入围方向都必须能在不依赖未知内部能力的情况下说清用户、产品、增长、收费和验证路径。
4. 对适合复用现有 Agent 的方向，立项说明书同时提供“复用公司底座”和“独立 MVP”两种实施口径，但不在未获得技术信息时编造接口和成本数据。

## 影响

- 选题空间从“多媒体 Agent 下游场景”扩展为“所有具有明确用户价值与商业可行性的 AI 应用产品”。
- 与申请人已有项目、行业经验和可演示原型相连的方向获得更高优先级。
- 基于公司底座的项目仍有资源协同和实施效率优势，但不应仅因为“能用底座”而被高估。

## 后续动作

1. 将申请人的 AI 虚拟试妆、生活服务商家 AI 转化和平台商业化经验纳入“可复用优势”评估。
2. 增加与申请人经验直接相关的候选产品，例如美业视觉决策与门店成交产品。
3. 下一轮将“个人信服力”和“公司资源协同”分开评分，避免两者互相代替。
