# TabTin 新人入门

> 状态：草稿
> 最后更新：2026-09-08
> 适用范围：有 Java 开发经验、刚接触 TabTin 的研发同事
> 关联文档：下方阅读索引

**TabTin 是一个让人和 AI 一起完成工作的工作台。** 你可以把目标交给 AI，也可以自己打开文档、表格等应用，随时让 AI 帮忙。

这套文档从“用户在做什么”讲到“代码在哪里”。先建立整体认识，再沿一个功能读代码。

| 顺序 | 阅读内容 | 读完能回答什么 |
| --- | --- | --- |
| 1 | [产品是怎么用的](01-产品是怎么用的.md) | 用户为什么用它？一次工作怎样完成？ |
| 2 | [核心概念](02-核心概念.md) | 组织、项目、工作空间、Agent 分别是什么？ |
| 3 | [用后端经验看架构](03-用后端经验看架构.md) | 哪部分像 Spring Boot？AI 在哪里执行？ |
| 4 | [一次任务如何完成](04-一次任务如何完成.md) | 发出一句话后，模型、工具和后端怎样配合？ |
| 5 | [第一周上手路线](05-第一周上手路线.md) | 先体验什么、读哪些代码、怎样开始联调？ |

第一次先读前两篇，打开产品试一次；准备看代码时再读后三篇。

你当前使用菜单 35 的轻量环境，具体本机 / test 分工见第五篇。让 AI 开发或修 bug 时，使用代码仓库里的 [harness 入口](/Users/yang/Documents/larchiveai/TabTin/harness/README.md)：先用 CodeGraph 定位，再按模块读边界和验证方法。

学完的目标只有三个：**能向同事解释产品、能亲手完成一个小任务、能找到一个接口的处理链路。**
