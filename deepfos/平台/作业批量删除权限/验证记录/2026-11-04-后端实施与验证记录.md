## 验证结果

环境为 Java 21、Maven 3.9.11。从仓库根执行：

```sh
mvn -pl system-server -am -DskipTests=false -Dtest=JobServiceImplBatchRemoveTest -Dsurefire.failIfNoSpecifiedTests=false test
```

结果：`BUILD SUCCESS`，`Tests run: 20, Failures: 0, Errors: 0, Skipped: 0`。相关依赖模块与后端源码编译通过，`git diff --check` 通过。

覆盖内容：

- 企业管理员无需逐应用检查，直接按本企业索引删除。
- 空间管理员可以删除本空间他人提交及空间级记录，其他空间记录拒绝。
- 应用管理员全部应用授权时允许；任一应用未授权则整批拒绝，既有上下文 `appAdmin` 标记不能代替全部应用校验。
- 用户组授权传递到既有角色 Mapper。
- 普通用户、开发者、空间成员／消息管理员、日志审计员不能仅凭这些身份删除本人记录。
- 空应用、空白应用、`0` 应用不能通过应用管理员分支。
- 第 1001 条记录属于未授权应用时，完整读取两页后拒绝，主作业和明细均无删除调用。
- 缺少主记录的 ID 不进入非企业管理员的明细删除集合；全部无主记录时拒绝。
- 权限依赖异常、空用户、空空间不能继续删除。

首轮测试暴露出框架业务异常构造依赖 Spring 国际化上下文；专项测试通过局部模拟该既有依赖解决，没有修改业务异常框架或新增测试依赖。
