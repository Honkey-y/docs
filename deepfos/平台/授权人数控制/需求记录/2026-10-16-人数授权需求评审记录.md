## 2. License 授权配置
### 2.1 是否控制人数
通常生产环境需要控制人数，非生产环境可不控制。是否控制由 License 中的授权人数决定：

| 授权人数 | 业务含义 |
| --- | --- |
| 正整数 | 按指定人数控制，例如 100 表示授权上限为 100 人 |
| 0 | 不限人数 |
| 未填写、负数、小数或其他非法值 | 授权人数异常，不视为人数不限 |


沿用 License 文件中的 `authorized_users` 字段。签发及平台读取时校验，校验失败沿用现有未授权处理，并在授权页展示具体错误原因。

### 2.2 顾问账号额度
约定授权用户数时统一计入顾问名额，签发 License 时将约定的总人数写入 `authorized_users`。平台不单独识别顾问账号，人数展示与校验统一使用该总额度。

## 3. 人数控制
### 3.1 环境已占用人数统计
环境已占用人数指当前环境内已启用且至少属于一个企业的用户数，超级管理员不计入。同一账号跨企业、空间、应用只计一次。

### 3.2 重点操作校验与提示
开启人数控制后，在以下操作提交时，按 3.1 计算本次操作生效后的环境占用人数。超过授权用户数时，提示错误并拦截整个操作；未超过时允许提交。校验在变更生效前完成，不能先执行再判断。

| 操作 | 入口 | 校验范围及超额处理 |
| --- | --- | --- |
| 创建用户 | 企业、空间成员管理中创建已启用用户 | 按本次创建后的占用人数校验，超额则整次创建不生效 |
| 启用用户 | 企业成员管理中编辑用户，将状态改为“启用”并保存；受邀用户激活账号后，在登录后的账号信息完善页点击“确定” | 按本次启用后的占用人数校验，超额则拦截提交，保持原账号状态 |
| 导入用户 | 企业、空间成员管理中提交包含“用户”的导入 | 按整次导入生效后的占用人数校验，超额则整个导入不执行；不包含“用户”的导入不校验 |


其他操作不增加本次人数校验。

批量操作按一次提交整体校验；同时包含新增、启用、禁用或移除等变更时，按全部变更后的最终人数计算。对应接口须保证校验与变更一致，避免并发提交造成超额。

校验失败时，在当前页面或处理结果中提示：

> 操作失败：本次操作后环境占用人数将超过授权用户数。授权用户数 {上限} 人，当前已占用 {占用} 人，本次操作后预计占用 {预计占用} 人，超出 {超额} 人。本次操作未执行，请调整本次操作、释放名额或增加授权用户数后重试。
>

例如授权 100 人、已占用 98 人时，整批新增 10 个占用用户，预计占用 108 人，整批拦截；新增 2 个占用用户后为 100 人，允许提交。

### 3.3 超额时的使用限制
开启人数控制且环境已占用人数超过授权用户数时，仅超级管理员可操作，其他用户由网关统一限制平台访问，包括已登录用户的后续请求。人数恢复至授权范围后解除人数限制。

现有 License 网关拦截场景（如硬停、未授权或授权无效）本次调整为采用相同原则：仅超级管理员可操作，便于处理授权及用户问题。

受限用户访问时，沿用现有授权硬停提示页的样式，展示以下文案，并在下方提供“重新尝试”次按钮，点击后返回原访问页面，重新校验访问资格。

> 当前环境授权人数已超额，暂时无法使用平台。请联系系统管理员处理。
>

## 4. 人数展示与管理
### 4.1 授权管理页
授权概览中，原“授权用户数”改为展示“环境已占用人数 / 授权用户数”，例如“80 / 100”。环境已占用人数按 3.1 统计，授权用户数为当前 License 的总额度；不限人数时显示“80 / 不限人数”，缺失值显示“-”。环境已占用人数超过授权用户数时，仅占用数字标红；不限人数时不标红。

字段旁展示小问号，悬停或聚焦时提示：

> 环境已占用人数指当前环境内已启用且至少属于一个企业的用户数，超级管理员不计入，同一用户只计一次。
>

进入授权概览、从通知切回授权概览或刷新浏览器时获取最新人数。

### 4.2 企业成员管理页
仅在企业成员列表工具栏的搜索区域旁展示人数及小问号，不单独占行：

> 本企业占用 / 环境授权：{企业占用} / {授权用户数} ⓘ

例如“本企业占用 / 环境授权：30 / 100”。分母为环境共享授权总人数，不是分配给当前企业的独立额度。不限人数时显示“30 / 不限人数”；人数缺失或无法计算时，对应位置显示“-”。

企业占用按本企业全部成员中符合 3.1 条件的用户统计，不随搜索、筛选或分页变化。悬停或聚焦时提示：

> 本企业占用是指本企业内已启用的用户数，超级管理员不计入。环境已占用人数及用户明细由超级管理员在管理后台“环境用户管理”中查看。

进入页面、切换企业或完成影响人数的变更后更新数据。成员列表沿用现有查看权限。

同一用户只展示一行，按账号创建时间降序排列，支持分页。列顺序及展示如下：

| 列 | 展示规则 |

**导出与批量禁用**

+ **导出**：由后端生成 Excel 文件，浏览器直接下载。导出当前已生效搜索、筛选条件下的全部用户，不限当前页。文件名为 `EXPORT_USER_yyyyMMddHHmmss.xlsx`，例如 `EXPORT_USER_20261016173753.xlsx`。导出字段依次为用户ID、用户名、昵称、手机号、邮箱、状态（1：启用；2：禁用；3：激活；4：未激活）、关联企业、创建时间、名额占用。
