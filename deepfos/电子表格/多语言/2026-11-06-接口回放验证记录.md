# 电子表格 Sheet 名称多语言接口回放验证记录

> 验证日期：2026-11-06
> 被测分支：`codex/sheet-multilingual`（提交 `df6ff9b` DeepTable 支持 Sheet 名称多语言）
> 本地运行：`deep-table-boot`，`--spring.profiles.active=test`，端口 `18089`，平台地址指向 `https://test.deepfos.com/deepfos-server`
> 抓取来源：`test.deepfos.com` 电子表格编辑态 / 使用态页面（Playwright），回放时仅替换为本地 IP

## 一、抓取到的页面接口

| 场景 | 接口 |
| --- | --- |
| 编辑态（浮动行表 / 动态表） | `GET /workbook/find-button`、`GET /workbook/get-default-theme`、`GET /workbook/find-info` |
| 使用态（浮动行表 / 动态表） | `GET /workbook/data-query-pre`、`POST /workbook/query-filter-v2`、`POST /workbook/query-sheet-baseplate-V2`、`POST /workbook/data-query-V2` |

两类表格使用态请求的差异仅在 `workbookFolderId`/`workbookName`/`sheetIdList` 与筛选器参数。

符合文档约定的默认值与前端回退语义。

## 三、正向多语言验证

为验证真实译名路径，以页面保存请求为模板补充字段后调用本地 `POST /workbook/save-info`：

```json
{
  "enableSheetNameMultilingual": true,
  "sheetScriptArrayStr": "sheet_id=SHT91f64068927e4ff68b78a07b3c2ee80f\nsheet_name=Sheet1\nmultilingual={\"en\": \"Income Statement\", \"fr\": \"Compte de résultat\", \"zh-cn\": \"利润表\"}\n..."
}
```

`POST /workbook/check-info` 先校验通过，再保存。随后按不同 `language` 请求头回放同一 `query-sheet-baseplate-V2` 请求：

| language | enableShNameMultilingual | sheetDisplayName |
| --- | --- | --- |
| zh-cn | true | 利润表 |
| en | true | Income Statement |
| fr | true | Compte de résultat |
| pt（未配置） | true | null（回退原 sheetName） |

同时 `find-info` 返回 `multilingual={"en":"Income Statement","fr":"Compte de résultat","zh-cn":"利润表"}`，`data-query-V2` 的 `sheetList[].multilingual` 同样携带译名集合。

验证完成后已用原始内容回放保存恢复fixture：`enableSheetNameMultilingual=false`、`multilingual=null`、`sheetDisplayName=null`；底板、按钮、引用数据表、sheetConfig、筛选器与保存前一致（浮动表列 `numericInputMode` 按当前代码默认归一为 `raw`）。

## 四、注意事项

- 请求必须携带 `language` 头；同时携带两个同名头时服务端取第一个，回放脚本使用去掉语言行的 headers 文件逐语言覆盖。
- 旧版前端保存请求不携带 `enableSheetNameMultilingual`，新后端会按默认 `false` 落库，需前端按“编辑态返回的开关值”回传。
- 本地无 Nacos 节点时缓存日志出现 `getNacosAddressStream error`，不影响接口结果。
