# 电子表格多语言对接

> 状态为评审中，更新于 2026-11-05。
> 适用于 DeepTable 后端分支 `codex/sheet-multilingual`，待前端联调。
> 关联文档为 [DeepFos 文档索引](../../说明.md)。

接口路径省略服务前缀，示例仅列本次涉及的业务字段。

## 一、保存入参

以下接口使用相同的新增入参，压缩接口在压缩前的 JSON 中添加。

- `POST /workbook/save-info`
- `POST /workbook/save-info-zip`
- `POST /workbook/check-info`

| 字段位置 | 类型 | 说明 |
| --- | --- | --- |
| 顶层 `enableSheetNameMultilingual` | boolean | 是否开启 Sheet 名称多语言，默认 `false` |
| `sheetScriptArrayStr` 内每张 Sheet 的 `multilingual` | JSON 对象文本 | 语言编码到译名的映射，随该 Sheet 的 `sheet_id` 提交 |

```json
{
  "enableSheetNameMultilingual": true,
  "sheetScriptArrayStr": "sheet_id=SHT001\nsheet_name=Sheet1\nmultilingual={\"en\":\"Income Statement\",\"fr\":\"Compte de résultat\",\"zh-cn\":\"利润表\"}"
}
```

关闭开关、修改原名称或复制 Sheet 后，保存时携带对应的 `multilingual`。清空全部译名传 `{}`。

## 二、新增返回字段

以下为前端主对接入口，沿用现有查询入参。

| 接口 | 新增返回字段 |
| --- | --- |
| `GET /workbook/find-info` | 顶层 `enableSheetNameMultilingual`，`sheetInfoList[].multilingual` |
| `POST /workbook/query-sheet-baseplate-V2` | 顶层 `enableSheetNameMultilingual`，`sheetBaseplateDTOMap[sheetId].sheetDisplayName` |

编辑态返回开关和译名集合，`multilingual` 为对象，未配置时可为 `null`。

```json
{
  "enableSheetNameMultilingual": true,
  "sheetInfoList": [
    {
      "sheetId": "SHT001",
      "sheetName": "Sheet1",
      "multilingual": {
        "en": "Income Statement",
        "fr": "Compte de résultat",
        "zh-cn": "利润表"
      }
    }
  ]
}
```

使用态英文请求返回示例，前端按 `sheetId` 读取显示名。

```json
{
  "enableSheetNameMultilingual": true,
  "sheetBaseplateDTOMap": {
    "SHT001": {
      "sheetId": "SHT001",
      "sheetName": "Sheet1",
      "sheetDisplayName": "Income Statement"
    }
  }
}
```

`sheetDisplayName` 为字符串或 `null`。开启时返回当前请求语言的译名，未开启、空白或未配置当前语言时返回 `null`，前端回退显示原 `sheetName`。配置、跳转及数据定位继续使用原 `sheetName`。

复用 V2 查询逻辑的 `/workbook/query-sheet-baseplate-simple` 同样返回这些字段。数据查询的 `sheetList` 复用 Sheet DTO，也会自然携带 `multilingual`。
