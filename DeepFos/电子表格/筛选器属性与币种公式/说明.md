2026-10-28 需求变更：DFFILTER 恢复原两个参数与展示逻辑；新增 `DFEntityFilter(筛选器编码,显示方式)`，仅支持多版本实体维。名称模式跟随筛选器实际保留的形式：US 返回 US，[HK].[US] 返回 [HK].[US]；其余模式与原 DFFILTER 一致，不额外拼接父级描述或别名。普通实体维也报错，以用户补充确认为准。

撤销第三参数及 rf、dimMemberRef、selectedDimensionRef、memberRefs，保留原筛选值，不通过查询补父级。常量、单元格／绝对／跨 Sheet 引用继续支持；前端保存原公式及 formula／args／rc，按层解析 fn／st。DFEntityFilter 使用新增类型 6，旧 DFFILTER 仍为 3。内嵌名称模式经后端批查校验后可供 DFUD／DFCurrency 使用。

DFUD 读取指定成员或关系成员的属性；DFCurrency 返回当前 VALUE 金额口径的币种标签。EntityCurrency 取子实体本位币，ParentCurrency 与 ParentTotal 等父级节点取引用中直接父实体本位币，指定币种节点返回对应币种。本轮不改变上述规则和维度移动后的身份修复。

前后端本地接入包括解析保存、配置面板、使用态只读回填与分层批查；合法编辑态公式显示 #待查询，非法参数反馈错误。当前实现与验收以[功能与后端规范](规划/功能与后端规范.md)为准，原 2026-10-14／15 的第三参数及独立引用验证记录保留作历史，不再作为当前契约。

用户只负责电子表格后端，不负责维度及财务模型源码。币种解析采用 artifactId 为 `deep-currency-resolution` 的独立 POM 的 Java 工程和普通 JAR（同仓库 deep-currency-resolution 目录，纳入根聚合构建）：公共包只处理 VALUE 规则和传入成员快照，电子表格批查元数据、本位币及描述后本地调用；公开契约从首版即面向其他上层复用，不包含电子表格字段或服务 DTO。二方包发布及维护归属待团队明确，现有财务模型／维度服务改造不计入用户执行范围。

确认边界：不新增财务模型或维度币种业务 URL，不引入年、期间、场景、版本参数，不搜索活跃父级，不查询金额、执行汇率换算或合并计算，不推断任意自定义 VALUE。DFUD 预置属性范围为 isBase、aggWeight、level、sharedMember、baseCount、localCurrency 六个；电子表格映射既有成员字段，自定义 UD 继续沿用原链路，权限及字段适用性仍须核验。
