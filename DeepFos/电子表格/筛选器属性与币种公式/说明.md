DFFILTER 保留筛选器选中的父子引用，Parent.Child 在五种显示方式下分别输出父、子展示；DFUD 读取指定成员或关系成员的属性；DFCurrency 返回当前 VALUE 金额口径的币种标签。EntityCurrency 取子实体本位币，ParentCurrency 与 ParentTotal 等父级合并节点取引用中直接父实体本位币，指定币种节点返回对应币种。

DFFILTER 的第三个参数由前端解析为 `tag.DF.rf`，省略时保持 Child 行为；前后端统一使用 rf 字段。

2026-10-15 补齐 DFFILTER 单元格引用：支持 `=DFFILTER(C30,D30,E30)`、绝对引用及跨 Sheet 引用。保存保留原始公式和 formula／args／rc，待引用就绪后由前端解析为 fn／st／rf，携带当前筛选值及 dimMemberRef 批查；后端复用既有五种显示方式与父子格式。未就绪时不校验单元格地址为业务枚举、不使用旧结果，解析后的非法参数仍报错。

筛选器完整关系使用独立字段：使用态参数 dimMemberRef、底板／筛选器配置 selectedDimensionRef、记忆值 memberRefs；旧筛选值保持不变。前后端本地链路已接入，维度类型按需通过现有缓存批查补齐，目标环境联调仍待完成。

当前接入状态：DFFILTER、DFUD、DFCurrency 均已完成前端本地接入。DFUD／DFCurrency 支持解析保存、配置面板、使用态只读回填及按依赖层批量查询；DFUD 可在数据源面板新增 DIM。合法公式在编辑态显示 #待查询，非法参数仍反馈公式错误。当前已通过本地测试和浏览器验证，DFUD／DFCurrency 的业务数据、权限及模型结构仍须目标环境联调，不能视为已正式发布。

重启后的本地代理查询已验证显示方式 5：实际返回 `[香港别名-香港].[美国别名-美国]`，无公式错误；详见实现记录。

用户只负责电子表格后端，不负责维度及财务模型源码。币种解析采用 artifactId 为 `deep-currency-resolution` 的独立 POM 的 Java 工程和普通 JAR（同仓库 deep-currency-resolution 目录，纳入根聚合构建）：公共包只处理 VALUE 规则和传入成员快照，电子表格批查元数据、本位币及描述后本地调用；公开契约从首版即面向其他上层复用，不包含电子表格字段或服务 DTO。二方包发布及维护归属待团队明确，现有财务模型／维度服务改造不计入用户执行范围。

确认边界：不新增财务模型或维度币种业务 URL，不引入年、期间、场景、版本参数，不搜索活跃父级，不查询金额、执行汇率换算或合并计算，不推断任意自定义 VALUE。DFUD 预置属性范围为 isBase、aggWeight、level、sharedMember、baseCount、localCurrency 六个；电子表格映射既有成员字段，自定义 UD 继续沿用原链路，权限及字段适用性仍须核验。
