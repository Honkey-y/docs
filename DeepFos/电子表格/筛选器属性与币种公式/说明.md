# 筛选器、属性与报表币种公式

关联需求：ReqP_00486；需求尚未实施，当前交付规范和可执行的后端计划。

DFFILTER 保留筛选器选中的父子引用；DFUD 读取指定成员或关系成员的属性；DFCurrency 返回当前 VALUE 金额口径的币种标签。EntityCurrency 取子实体本位币，ParentCurrency 与 ParentTotal 等父级合并节点取引用中直接父实体本位币，指定币种节点返回对应币种。

用户只负责电子表格后端，不负责维度及财务模型源码。币种解析采用 artifactId 为 `deep-currency-resolution` 的独立 Java 工程和普通 JAR：公共包只处理 VALUE 规则和传入成员快照，电子表格批查元数据、本位币及描述后本地调用；公开契约从首版即面向其他上层复用，不包含电子表格字段或服务 DTO。二方包发布及维护归属待团队明确，现有财务模型／维度服务改造不计入用户执行范围。

确认边界：不新增财务模型或维度币种业务 URL，不引入年、期间、场景、版本参数，不搜索活跃父级，不查询金额、执行汇率换算或合并计算，不推断任意自定义 VALUE。DFUD 预置属性范围为 isBase、aggWeight、level、sharedMember、baseCount、localCurrency 六个；电子表格映射既有成员字段，自定义 UD 继续沿用原链路，权限及字段适用性仍须核验。
