## 目标与范围

让 `/log/enterprise/log-list` 和 `/job-current-list` 返回 `ip`，并让 `/job-current-export` 导出的 Excel 追加 IP 列。操作日志沿用已有 IP 数据；作业在创建时保存来源 IP，未完成时存入关系数据库，结束归档时保留到 Elasticsearch（下文简称 ES）。

本次包含后端响应、作业来源地址持久化和主作业 Excel 导出 IP；不增加前端列、IP 查询条件或新的搜索后端。

## 已定方案

1. 来源 IP 采用 `RequestContext.getParams()` 中的 `ip`，与操作日志保持一致。该方法读取当前 `CustomContext.getParams()`；上下文缺失时允许空值。
2. 在作业创建服务构造 `JobCurrent` 后集中赋值，覆盖数据库创建和直接 ES 创建；不增加调用方必传参数。
3. 作业来源 IP 在生命周期中保持不变，更新、暂停、恢复、取消及超时均不取当前操作者的 IP 覆盖它。
4. 作业数据库增加可空 `ip` 列，补齐显式插入、查询列和结果映射；ES 既有索引与未来索引的字段映射都须处理。
5. 历史作业没有可靠 IP 时保持空值。操作日志已有 IP 按原值返回，不执行全量重建或改变原字段类型。
