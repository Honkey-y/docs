## 一、阶段一：引擎与原生报告

- 代码位置：`deep-jmeter/backend/core/`，普通 Java 核心，无账号、数据库或 Spring Security 依赖。
- 环境：JDK 21.0.9、Maven 3.9.11、JMeter 5.6.3；后端父工程锁定 Spring Boot 3.5.16 依赖管理。
- 验证命令：设置外部 `JMETER_HOME` 后运行 `mvn -B -f backend/pom.xml verify -ntp`。
- 结果：3 个测试通过、0 失败、0 跳过；包含真实临时 HTTP 服务、12 个样本/6 个失败、六类图表、CSV 公式防护、HTML ZIP 以及独立进程停止。
- 统计一致性：Web 统计树直接与原生 `statistics.json` 比较相等；图表读取原生 `graph.js` 的 JSON 数据段，不执行脚本。错误表同样直接读取原生数据。
- 边界：这是本机低负载功能验证，不作为生产压测容量。报告适配只支持锁定版本，原生输出变化须重新验证。

## 二、阶段二：分层、持久任务与报告接口

- 代码：6个独立Controller、6个Service接口及Impl；DTO/PO/VO分包，MyBatis接口与Mapper XML，无业务Java SQL或JdbcTemplate。核心按engine、plan、report、contract分包。
- 任务：主表、配置快照、执行明细、报告头、生成历史分别存储，列表用序号游标与批量汇总读取；数据库不逐条保存压测样本。
- 升级：按用户要求移除Flyway/Liquibase，使用简单升级记录表、摘要校验与MySQL命名锁，已成功执行则跳过。dev/lease分别配置，线上参数外置。
- 自动验证：9个测试全部通过、0跳过（core 3、app 6），覆盖真实引擎API闭环、幂等冲突、旧结果导入、CSV/ZIP、原生预览沙箱、Redis故障回源、升级跳过、SQL分句和分层约束。
- 真实环境：项目专用MySQL 5.7.44库和账号；Redis 5.0.8采用RESP2。仅操作本项目库，配置文件被Git忽略，凭据不写入记录。
- 真实API验收：本地回环HTTP产生6个样本/3个失败，六类图表、484字节汇总CSV与约1MB HTML ZIP导出成功，Redis缓存可用。数据是真实测试结果，不代表容量。
- 中文备注：9张表（含升级历史）均有中文表备注，业务字段无缺失备注。
- 空表/低数据量EXPLAIN：任务领取命中`idx_tasks_queue`，游标命中`PRIMARY`，场景历史命中`idx_tasks_scenario_history`，报告领取命中`idx_task_reports_queue`；幂等唯一查询按常量索引优化。未做海量数据基准，不能保证任意规模的响应时间。
- 导出依赖：Commons CSV 1.14.1、Commons Compress 1.28.0，流式下载，统计同源。

## 七、场景与报告批量操作

2026-10-20根据用户四条浏览器批注实现；需求与交互规范已同步。当前仍使用同一开源核心、既有MyBatis持久层与本地文件，不新增数据库表、升级脚本、消息中间件或账号依赖。

- 场景导航：名称以外的来源、版本、时间及行空白可进入Web编辑或导入脚本查看，行聚焦后Enter/空格可用；复选框、运行、复制、归档保持独立。
- 批量导入：最多20份JMX、单份20MB，顺序上传及检查，每份单独命名和关联CSV。损坏文件单独报错，不影响就绪项；缺CSV的项不提交，成功项锁定，临时失败后只重试尚未成功项。
- 批量选择：场景与报告支持逐项、全选本页、半选状态、跨页累计和清空，最多50项。场景搜索变化清空选择；未选择时禁用导出按钮。
- 后端接口：`POST /api/v1/scenarios/exports` 与 `POST /api/v1/reports/exports` 分属原业务Controller、Service和Impl，使用独立DTO和公开Commons Compress/IO。ID规范化并去重，空选、超限、非法ID和未知格式返回400，不存在返回404，未就绪报告返回409。
- 场景包：按安全名称和完整UUID区分同名场景，UTF-8目录长度受限，JMX与CSV分别保存。仅调整导出副本的附件引用，不改原始字节或解析线程占位符；草稿组件保留。下载ZIP整体重新导入及恢复Web配置模型不在本次支持范围。
- 报告包：固定成功报告批次，HTML内层ZIP可独立离线解压；汇总CSV导出全量标签，原始JTL字节保持一致。共享ZIP写入器隔离内层流关闭，避免多报告只导出第一份；数据按文件依次处理，不累计全部报告内容。
- 后端回归：设置JMETER_HOME后的Maven verify通过22项、0失败、0跳过（core 8、app 14）。新增验证包含重名/长Unicode名称、重复与大写UUID、相对附件、占位符和原始JMX不变、选择边界、缺失/未就绪、两份报告三种格式与内层ZIP内容。
- 浏览器回归：Chrome下2项完整流程同时通过（14.4秒）。包含真实本地HTTP压测、六图及原生预览、JMX多选/CSV映射、损坏文件、模拟一次503后成功项只提交1次且失败项提交2次、行空白导航与勾选/运行隔离、场景ZIP、两份报告的HTML/CSV/JTL批量下载。
- 下载产物复核：独立用ZIP读取器校验场景包为2份JMX/1份CSV，三种报告包均为2份报告；所有归档CRC检查通过，HTML内层含首页与OverTime趋势页。未用任意业务目标验证压测，执行请求只发往本机临时服务。
