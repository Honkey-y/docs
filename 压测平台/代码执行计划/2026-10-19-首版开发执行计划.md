## 一、授权与现状

2026-10-19 用户明确授权开始开发，每完成阶段可本地 Git 提交，提交信息与 README 等默认中文。当前代码仓库为 `main`，初始提交 `81393e4`，仅有 README，无 CodeGraph 索引。现有 JDK 21、Maven、Node、pnpm；本机已有 JMeter 5.6.3。文档仓库与代码仓库独立，分别只提交本任务文件，不推送、不发布。

用户未另选的细节沿用先前建议：先实现结束后的完整报告，运行中状态与日志；纳入已有 CSV JTL 导入；单节点、单任务执行；React/TypeScript 前端、Spring Boot 后端。账号与审计只保留最小通用边界，不实现账号系统或公司适配。MySQL、Redis、本地文件存储和无消息中间件约束不变。

## 二、阶段与验证

### 1. 引擎和原生报告适配

- 新建 `backend/pom.xml`、`backend/core/`，核心不依赖 Spring Security、用户表或公司包。
- 实现独立 JMeter 进程启动、任务级停止、超时与日志，报告生成独立重试。
- 原生 `statistics.json` 与图表脚本中的 JSON 仅作数据读取，不执行 JavaScript；锁定引擎版本并验证六类图表。
- 验证：随机本地端口 HTTP 服务产生成功/失败样本，与原生报告逐项对照；验证停止、CSV/ZIP 导出。
- 通过后中文提交阶段一，记录实际版本与测试结果。

### 2. 导入、持久任务和报告接口

- 新建 `backend/app/`，使用 MySQL 保存场景/快照/任务，Redis 仅作可回源缓存，文件保存受控相对路径。
- 实现 JMX/附件资产、场景导入、不可变版本、排队执行、停止、恢复、报告重试、日志与导出 API；保留空操作者与事件接口。
- 校验 XML/组件/附件依赖，禁止脚本与宿主任意路径；只允许标准线程组显式覆盖。
- 验证：集成测试与本地启动验证，数据库仅操作本项目独立库，不改现有业务库；凭据通过忽略的本地配置提供。
- 通过后中文提交阶段二。

### 3. Web 配置、报告和界面

- 新建 `frontend/`，TypeScript、React、Vite、ECharts，采用暖中性画布、灰侧栏、白工作区与克制蓝色。
- 实现场景列表、JMX 导入、HTTP 配置、运行列表/日志/停止、六类报告图表、汇总与错误数据、HTML/CSV 导出和结果导入。
- Web 配置生成原生 JMX，基础请求、认证、变量、CSV、断言与 JSON 提取按真实 JMeter 验证。
- 验证：前端类型检查、构建及浏览器真实闭环，不生成演示指标，不依赖登录 Store 或账号接口。
- 通过后中文提交阶段三。

### 4. 恢复、部署边界与使用说明

- 检查重复提交、停止竞态、报告失败、无样本、磁盘不足、损坏上传、服务退出与重启恢复。
- 配置外置、路径可搬移、生命周期独立于 Docker；本轮不增加 Kubernetes 或分布式执行。
- 完善中文 README、配置模板、依赖/许可证待定说明和阶段验证记录，保留开源发行与公司配置分离。
- 验证：后端全套相关测试、前端构建、真实本地 HTTP 闭环、无账号环境验证；只在新改动或失败时重复检查。
- 通过后中文提交阶段四。
