## 一、项目定位

将 Apache JMeter 的脚本配置、执行、结果分析和报告导出集中到内部 Web 平台。首版的核心价值是：能够运行 HTTP/HTTPS 压测，在浏览器查看 JMeter 已有的趋势图与数据，并导出报告和数据。后续再拓展审计数据等能力。

文档目录独立放在 docs 根目录，与 `DeepFos/` 同级。产品代码将来统一放在 `/Users/yang/Documents/project/deep-jmeter/`，前端 `frontend/`、后端 `backend/` 分开。

## 四、建议方案，尚待整体确认

- 前端使用 TypeScript、React、Vite；图表使用 Apache ECharts。
- 后端使用 Java、Spring Boot、Maven；JMeter 作为独立进程执行。
- 首版单部署实例、单执行节点，默认一次执行一个压测任务；任务存 MySQL，后端轮询领取，Redis 仅用于缓存。
- 原生 HTML Dashboard 作为结果口径基准；Web 重绘常用图表，不要求首版逐一重做原生所有图表。
- 运行中先显示状态、日志与运行时间；完整趋势图在结果处理结束后展示。秒级实时趋势图不作为当前建议范围。
- 导入脚本保留原始文件，有限度修改标准线程组和参数；Web 配置器先覆盖基础 HTTP 场景。
- 增加已有 CSV 格式 JTL 结果导入，直接生成报告。
- 首版部署访问控制、负载与保留期限须在实施前明确；完整组织权限和业务审计暂缓。
