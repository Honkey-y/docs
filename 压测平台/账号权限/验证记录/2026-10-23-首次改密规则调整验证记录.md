产品提交：`codex/account-login / ec243e7`，基准 `be6bb60`。用户明确要求：admin首次登录无需改密，自主注册无需改密，只有由他人创建的用户需要首次改密。本次不推进人员管理计划，代建／导入管理入口仍待第三计划；管理员重置普通用户密码后的强制改密及会话撤销保持有效。

## 一、实际行为

| 账号情形                 | 改密要求及访问结果                                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 新初始化的admin          | 初始密码仍为admin，首次登录直接进入管理页，可访问账号安全；项目业务仍返回ADMIN_SCOPE_ONLY                             |
| 已有admin保留旧标记      | 启动核验初始化记录和内置管理员身份后，仅清除must_change_password；不覆盖密码摘要或账号状态                            |
| 自主注册                 | 保持现有must_change_password=false，登录后直接进入默认团队                                                            |
| 管理员代建／导入普通用户 | 仍使用must_change_password=true；登录后进入改密页，业务请求返回PASSWORD_CHANGE_REQUIRED；修改成功并重新登录后解除限制 |
| 管理员重置普通用户密码   | 继续设置强制改密并撤销目标全部Token，不因本次admin免改密规则而豁免                                                    |

实现位置为 `backend/account/src/main/java/io/deepjmeter/account/service/impl/AccountServiceImpl.java`、`mapper/AccountUserMapper.java` 和 `resources/mapper/AccountUserMapper.xml`。兼容处理的SQL限定初始化记录对应的id、保留登录名admin、SUPER_ADMIN类型和当前待改密状态；不修改密码字段，不清除普通用户的改密标记，无DDL或数据库重刷。
