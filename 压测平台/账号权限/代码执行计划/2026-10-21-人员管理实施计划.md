## 一、目标与当前依据

交付超级管理员人员管理、快捷创建、重置密码／启停／解锁、CSV 用户导入导出及全局角色分配，同时完成团队成员、邀请与加入流程。依赖登录、代建账号首次改密和团队项目授权；当前没有这些账号界面和接口，下列入口均为拟新增。不做邮件短信发送、企业通讯录或申请审批。

## 二、实施步骤

1. **实现全局账号维护**：账号模块新增 `/api/v1/admin/users` 列表／快捷创建／资料修改及密码重置、启停、解锁子接口，按既有分层编写 Service、DTO／PO／VO 与 Mapper XML。代建用户必须设置首次改密（自主注册及内置admin免首次改密）。仅超级管理员可用，禁止创建第二个超管或修改内置管理员类型／启停状态。重置设置强制改密并调用会话服务删目标用户全部 Redis Token；停用同样撤销，解锁只清失败计数和临时锁，不启用被停用账号。验证普通团队管理员不能调用全局维护接口。
2. **实现 CSV 用户导入导出**：新增管理端 `/imports/preview、imports、exports` 的 POST 入口，使用 Apache Commons CSV 和规范字段；导入以限长 `text/csv` 正文解析，避免含初始密码的 multipart 落入明文临时文件。预检展示行号、错误及新增／更新数量，不回显密码；提交复核摘要／版本并整批事务和幂等，新增强制改密，更新禁止改密或提权。导出普通账号基本信息并防公式注入，排除 admin 和全部密码／Token。验证行数大小、重复／保留名、非法状态、事务失败和重试，含停用的更新复用删 Token 逻辑。
3. **实现全局角色分配**：新增 `/api/v1/admin/users/{id}/roles` 与专用团队／项目角色目录接口，仅返回分配所需元数据，不调用业务详情或授予超管项目上下文。为普通用户分配任意团队／项目固定角色，项目缺少团队成员关系时补普通成员；所有者变化同事务转移，批量角色修改整体校验。验证跨团队授权、执行者选项、两人抢占所有者，以及超管不能给自己分配业务角色。
4. **实现团队成员及转移**：分别设置团队／项目成员 Controller、Service 与 XML，团队路径 `/api/v1/teams/{teamId}/members`，项目路径 `/api/v1/projects/{projectId}/members`。普通管理规则仍按矩阵，不能借团队角色维护全局账号；团队 `/leave、ownership` 使用 POST，移除／退出撤销全部项目角色，所有者须先转移。验证并发冲突、任一批量项失败整体回滚、移除后下一请求无权且历史任务保留。
5. **实现邀请与原子加入**：新增邀请及接受记录模型／XML，团队 `/invitations` 签发／列表／撤销，公共 `/api/v1/invitations/preview` 与登录后的 `/accept` 均用 POST 正文传码。接受时锁邀请，先处理已有接受记录，再核验有效期、人数、签发者实时权限及项目归属，原子写成员和次数。邀请允许四种项目角色但不能产生团队管理员。验证最后名额竞争、重试幂等、退出后旧接受记录不能恢复，以及签发者失权链接失效。
6. **实现人员与邀请界面**：`App.tsx` 注册可选“人员管理”入口，复用现有表格／分页／表单和 `ConfirmDialog`；超管提供快捷创建、重置／启停／解锁、导入预检、导出及跨团队角色表，仅展示团队／项目名称，不显示进入项目链接。普通账号保留团队“成员、待定邀请”和成员详情，邀请接受页沿用登录表单布局，确认后才加入。角色表含执行者及不可修改的继承说明；验证各身份入口、CSV 错误、空态和窄屏。

## 三、验证与完成标准

- [x] 成员、邀请、详情及确认弹窗与当前业务列表／弹窗截图对照，颜色、行高、按钮和分页一致；桌面／窄屏、长昵称、批量角色、空态及邀请失效均无布局溢出。
- [x] 超管登录后无需首次改密即可快捷建用户、重置／启停／解锁、导入导出及跨团队分配角色；任何操作均不赋予其项目内容访问权。
- [x] 重置／停用立即删除目标全部设备 Token，停用保留所有权和历史，重新启用不恢复旧 Token；管理员本身不可停用／降级。
- [x] CSV 仅维护普通账号基础信息；新增必改密，更新不改密／提权，错误整批失败，重复提交不重复创建，导出不含密码及 Token。
- [x] 所有者可任免管理员、转移所有权；管理员不能修改所有者和其他管理员；项目管理员不能修改其他项目或拉人入团队。
- [x] 未登录开链接可查看最小预览，登录不会自动加入；确认加入成功后团队出现在左侧，项目权限与邀请一致。
- [x] 同账号重复加入不重复计数、改角色或产生关系；不同账号争抢最后名额仅一个成功，事务失败无部分成员残留。
- [x] 被移除／退出者下一请求不能访问该团队任何项目，旧缓存及链接不能恢复；场景、运行、报告不级联删除。
- [x] 邀请随机码、密码和 Token 不进入普通请求日志，人员及全局角色变化记录必要操作者与结果，不扩建完整审计中心。

按入口文档执行格式、后端集成及邀请浏览器回归并本地提交。邀请记录须持久化，不能只放 Redis；回退保留关系和接受记录，通过匹配数据备份恢复，不重新公开已撤销链接。
